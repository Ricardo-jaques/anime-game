# 🎮 Anime Game

Projeto pessoal desenvolvido para praticar **lógica de programação, JavaScript e desenvolvimento web**, utilizando personagens de diferentes animes como temática principal.

O projeto foi criado durante meus estudos como uma forma de transformar os conhecimentos aprendidos em um projeto prático e divertido.

## 📌 Sobre o projeto

O **Anime Game** reúne personagens conhecidos de diferentes obras de anime em uma experiência interativa desenvolvida para navegador.

Entre os personagens utilizados estão:

* 🔥 **Sukuna** — *Jujutsu Kaisen*
* ⚡ **Goku** — *Dragon Ball*
* 💥 **Midoriya** — *My Hero Academia*

Além de colocar a programação em prática, o projeto também foi uma oportunidade para experimentar diferentes formas de interação com o usuário e trabalhar com elementos visuais.

## 🛠️ Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript

## 📚 Conceitos praticados

Durante o desenvolvimento, foram colocados em prática conceitos como:

* Variáveis
* Condicionais
* Funções
* Manipulação de elementos HTML
* Eventos
* Strings
* Arrays
* Métodos e propriedades do JavaScript
* `.length`
* `.includes()`
* Manipulação do DOM
* Lógica de programação

## 🎯 Objetivo

O principal objetivo deste projeto é **praticar programação através de um projeto próprio**, aplicando conhecimentos estudados durante o curso de Análise e Desenvolvimento de Sistemas na SPTech.

Este projeto também serve como registro da minha evolução durante o aprendizado de desenvolvimento web e programação.
